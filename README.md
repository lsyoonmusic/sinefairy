# Sine Fairy v1.1 (HQ Lookahead Edition) — by ASIMORPH's Fellas

DAW 자동 레이턴시 보정(PDC: `4096` 샘플 = `85.3 ms @ 48 kHz`, `8192` 샘플 = `85.3 ms @ 96 kHz`)을 활용해 실시간 제약을 풀고, **최대 20배음까지 위상 동기 사인파 재구성**과 **선형 위상 브릭월 로우컷**을 구현한 스튜디오용 하모닉 디노이저·리컨스트럭터 VST3입니다.

---

## v1.0 → v1.1 핵심 업그레이드

1. **"옹알옹알" 맥놀이 제거 — 직교 락인 폐기 & PLL 결합 McAulay-Quatieri 3차 위상 SMS 도입 (`HarmonicFrameAnalyzer.h`, `PhaseLockedSmsSynth.h`)**
   - 4096-pt 영위상(Zero-Phase Shifted) 스테레오 Hann FFT에서 좌/우 각 채널의 정확한 배음 피크 주파수 $f_k$, 노이즈 플로어 차감 진폭 $A_k$, 프레임 정중앙 순간 위상 $\theta_k$를 추출합니다.
   - 홉 경계를 연속 위상 PLL + 3차 위상 다항식으로 연결해 원음과 섞어도 **콤 필터링이 전혀 없으면서(`-0.08 dB`, 상관도 `0.998`)** 직교 락인 특유의 옹알거림과 홉 레이트 위상 지터 사이드밴드를 제거했습니다.
2. **최대 20배음(`H1 ~ H20`) 고차 배음 재구성 & 4존 톤 쉐이핑**
   - `HARMONICS (1..20)`으로 저역 1~4배음 머드 정리부터 12~20배음 고차 배음 재구성까지 폭넓게 제어할 수 있습니다.
   - `H1 (FUND)`, `H2 (2x)`, `H3-H4`, `H5-H20` 4개 존 트림(`0..200%`)과 `PURITY GATE (0..100%)`로 재구성 순도와 배음 밸런스를 정교하게 다듬습니다.
3. **"꿀렁꿀렁" 피치 도약 방지 — 5프레임 논코잘 룩어헤드 & Partial Birth/Death (`SineFairyV11Engine.h`)**
   - 정중앙 대칭 YIN + FFT 배음 스코어링 + `H1..H6` 로그-포물선 보간으로 오차를 `±0.1~0.5센트` 수준으로 개선하고, 4홉(42.7 ms) 미래 룩어헤드로 단발성 옥타브 튐을 지연 없이 제거합니다.
   - `0.75 반음` 이상 음정 도약 시 글리산도 없이 기존 배음은 페이드아웃(Death), 새 음 배음은 정확한 새 위상으로 페이드인(Birth)합니다.
4. **선형 위상 / 최소 위상 서지컬 로우컷 (`OFF ~ 96 dB/oct + BRICKWALL`)**
   - `LINEAR PHASE` (8배 중첩 WOLA, 위상 왜곡 0)와 `MIN PHASE` (룩어헤드 유도 16차 Butterworth TPT SVF, 프리링잉 0)를 전환할 수 있습니다.
